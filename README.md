# 赛博塔罗 · 第 3 课 V0.3

在 V0.1 的普通键盘事件、5 张示例牌、单张抽卡和固定解读基线上，增加一次性启动问候、S2 牌组/牌阵步骤，以及适配 Easy Input 系统语音输入的 S3 问题流程。鼠标、电脑键盘与开发板键盘事件继续共用同一套动作逻辑。没有调用模型、真实 AI 解读、项目 API 密钥或设备私有协议。

## 本地启动

在此目录运行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:4173/ 。需要通过 HTTP 服务打开，不能直接双击 HTML（包含 JS 模块；浏览器语音能力也要求安全来源，localhost 可用）。

## 第 3 课互动

- 用户首次按 S1、数字键 1 或点击“开始抽卡”时，网页在该次用户操作内立即调用浏览器语音合成，播放短句“欢迎回来。想好问题，我们开始吧。”同一标签页只尝试一次，刷新和重抽不会重复播放。
- S1 后进入牌组/牌阵步骤；按 S2、数字键 2 或点击主按钮，会确认当前实际可用的“五张示例牌组 + 单张指引”，随后立即聚焦问题框。
- Easy Input 的 S3 保持“语音输入”功能。它不是网页键盘事件，而是把系统转写文字写入当前焦点；因此 S2 完成后，S3 的文字会直接进入问题框。数字键 3 / 小键盘 3 仍可作为电脑键盘的“聚焦问题框”备用动作。
- 页面提供待机、正在聆听、已停止、等待确认和失败状态。浏览器 `SpeechRecognition` / `webkitSpeechRecognition` 只作为额外备用入口；不支持、无麦克风、权限被拒绝或识别失败时，S3 系统语音输入或普通文字输入仍可继续。
- 语音输入或识别结果只是草稿，可以查看和修改。只有点击“确认问题”后，问题才写入当前占卜会话；刷新会随牌组恢复，重新开始会清除。
- 本课不接真实 AI，不做历史统计，不发布正式网站。

## 已沿用的 EasyInput 配置（本课禁止修改）

依据第 6 课第 4、5 章：https://waytoagi.feishu.cn/wiki/A64iwQCt5i0T1wkjHqGcMd6OnZf

1. V0.1 已同步：S1 为数字键 1，旋钮为左右方向键，旋钮短按为 Enter。
2. 本课不操作 EasyInput App，不修改或同步开发板键位，不烧录、不复位、不修改固件。
3. S2 需要继续发出数字键 2 / 小键盘 2，才能触发网页的组合选择动作。实体 S3 不需要发出数字键 3，应保持现有“语音输入”配置；网页通过 S2 后自动聚焦输入框来承接转写。
4. 网页“输入验证”显示接收到的 code、有效次数、被忽略的重复事件。开启“仅测试输入”可以只测输入，不启动语音或推进抽卡。
5. 数字键 1、2、3 分别绑定开始、确认当前组合、聚焦问题框；其余数字键仍只记录输入。Numpad1–8 与 NumpadEnter 兼容。Easy Input S3 的系统语音转写不会显示为 Digit3，这是正常现象。
6. “仅测试输入”复选框保持焦点时也能接收测试键；其他输入框、下拉框、可编辑区或说明标题仍保留原本的键盘操作，弹窗期间按键交给弹窗。

网页不能检测实际硬件连接，不能区分开发板与普通键盘。不显示虚假的“已连接”。按住输入忽略浏览器 repeat 和未释放的重复 keydown；真实固件若发送多组完整按下/松开，网页会如实计数，需要进一步定位。左右方向和一格几次由固件配置及真机决定。

## 抽卡规则

- 按 1 或点击开始进入组合步骤；按 2 / S2 或点击主按钮后仅洗牌一次。随后旋钮/方向键循环选择，点击牌背也可选择。
- 回车/旋钮短按或点击确认揭牌；结果来自已洗好的牌组，之后方向、开始、再次确认都不会更改。
- 已确认问题与当前结果保存在本标签页 `sessionStorage`，刷新可恢复；关掉标签页不作为长期保存。存储被禁用时页面明确提示。
- 重抽必须使用“结束本次，重新抽牌”并确认。纯键盘可用 Tab 导航到此按钮，再用空格激活。
- 固定解读仅供娱乐和自我反思；示例插图为 AI 生成的统一视觉素材，不代表标准塔罗图像。5 张示例为星星、月亮、太阳、愚者、隐者，未包含逆位或完整 78 张牌。

## 验证

运行 `node --test tests/core.test.mjs`。覆盖 S1/S2 状态推进、旋转、重复按下、锁定、恢复、无效保存数据、鼠标和键盘共用流程、电脑数字键 3 备用映射、问题确认与旧会话兼容、麦克风失败时的文字降级提示。

真机状态：

| 项目 | 步骤 | 预期 | 状态 |
|---|---|---|---|
| S1 | 测试模式短按 3 次 | Digit1 或 Numpad1，接受次数 +3 | V0.1 已真机通过 |
| S2 | S1 后短按一次 | 确认当前牌组/牌阵，并自动聚焦问题框 | 待本版本真机验证 |
| 长按 | S1 按住约 2 秒后松开 | 接受 +1，浏览器重复被忽略 | V0.1 已真机通过 |
| 旋钮 | 慢转右 10 格，再左 10 格 | 各方向接受 10 次；每格一次 | V0.1 已真机通过 |
| 短按 | 旋钮按下松开一次 | Enter 或 NumpadEnter，接受 +1 | V0.1 已真机通过 |
| 完整抽卡 | 关闭仅测试；S1、S2、S3 输入并确认问题、旋转、确认 | 单次揭牌；后续输入和刷新不换牌 | 待本版本真机验证 |

| 切换应用 | 切去其他应用再返回 | 本页未被后台键盘操作改变 | 待验证 |

测试记录详见 QA.md。只有用户观察真机后才把新增的 S3 真机状态改为通过。

## 板级边界

采用已读取的 easyinput-board-cy 板级资料：EasyInput V2.0 / v2 / AI Keyboard V2.1 指向同一基线。8 键及编码器为物理资源；产品动作属于本项目。网页只处理系统键盘事件，不直接接触 GPIO、共享外设电源、BOOT、Flash 分区或固件。本轮没有操作 EasyInput App、烧录或更改任何开发板配置。

# 赛博塔罗 · 第 3 课 V0.5

在 V0.1 抽卡和 V0.3 语音互动基线上，加入 1/3/5/10 张牌阵、完整 78 张 Rider–Waite–Smith 随机牌组、旋钮选牌与悬浮牌阵结果。鼠标、电脑键盘与开发板输入继续共用同一套动作逻辑。没有调用模型、真实 AI 解读、项目 API 密钥或设备私有协议。

## 本地启动

在此目录运行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:4173/ 。需要通过 HTTP 服务打开，不能直接双击 HTML（包含 JS 模块；浏览器语音能力也要求安全来源，localhost 可用）。

## 第 3 课互动

- S1 直接开始，S2 直接进入牌阵选择。网页在后台兼容固定文字“开始”“牌阵选择”、旧称“牌组选择”和数字键 1 / 2，不再显示固定文字输入框。
- 待机、等待 S2 和结果阶段会自动维持后台硬件焦点；切回页面或点击空白处后无需再点输入框，固定文字与数字键均可继续触发。
- 用户首次按 S1、按兼容数字键 1 或点击“开始”时，网页在该次用户操作内立即调用浏览器语音合成，播放短句“欢迎回来。想好问题，我们开始吧。”同一标签页只尝试一次。
- 牌阵选择包含单卡指引、时间之流、命运抉择和凯尔特十字四种结构，分别抽取 1、3、5、10 张。旋钮左右切换，短按确认。
- 确认牌阵后才随机洗牌。网页只呈现当前牌附近的 7 张卡背，但旋钮可以循环到完整 78 张；已抽出的牌不会重复出现。
- Easy Input 的 S3 保持“语音输入”功能。它不是网页键盘事件，而是把系统转写文字写入当前焦点；因此 S2 完成后，S3 的文字会直接进入问题框。数字键 3 / 小键盘 3 仍可作为电脑键盘的“聚焦问题框”备用动作。
- 页面提供待机、正在聆听、已停止、等待确认和失败状态。浏览器 `SpeechRecognition` / `webkitSpeechRecognition` 只作为额外备用入口；不支持、无麦克风、权限被拒绝或识别失败时，S3 系统语音输入或普通文字输入仍可继续。
- 语音输入或识别结果只是草稿，可以查看和修改。短按旋钮（Enter）或点击“确认问题”后，问题才写入当前占卜会话；刷新会随牌组恢复，S1 开始新一轮时清除。
- 完整实体流程无需鼠标：S1 开始 → S2 进入牌阵 → 旋转并短按确认牌阵 → S3 说话 → 短按确认问题 → 旋转并逐张短按选牌。抽足数量后牌阵悬浮显示，旋转可查看每张牌的信息；再次按 S1 进入新一轮。
- 本课不接真实 AI，不做历史统计，不发布正式网站。

## 已沿用的 EasyInput 配置（本课禁止修改）

依据第 6 课第 4、5 章：https://waytoagi.feishu.cn/wiki/A64iwQCt5i0T1wkjHqGcMd6OnZf

1. 网页现支持 S1 固定文字“开始”和 S2 固定文字“牌阵选择”；旧称“牌组选择”和数字键 1 / 2 仍兼容。
2. 本课不操作 EasyInput App，不修改或同步开发板键位，不烧录、不复位、不修改固件。
3. 若要让实体键显示并发送上述固定文字，需要用户在 Easy Input 中自行确认配置；本分支只负责网页兼容，不代为改键。S3 保持现有“语音输入”。
4. 网页“输入验证”显示接收到的 code、有效次数、被忽略的重复事件。开启“仅测试输入”可以只测输入，不启动语音或推进抽卡。
5. 数字键 1、2、3 分别兼容开始、牌阵选择、聚焦问题框；Numpad1–8 与 NumpadEnter 兼容。
6. 问题框有焦点时，Enter / NumpadEnter 用于确认问题；确认后相同按键逐张选牌。结果页会在后台等待 S1 的“开始”指令。

网页不能检测实际硬件连接，不能区分开发板与普通键盘。不显示虚假的“已连接”。按住输入忽略浏览器 repeat 和未释放的重复 keydown；真实固件若发送多组完整按下/松开，网页会如实计数，需要进一步定位。左右方向和一格几次由固件配置及真机决定。

## 抽卡规则

- “开始”进入本轮，“牌阵选择”打开四种牌阵；旋钮/方向键切换牌阵，短按确认后仅洗牌一次。
- 问题框有文字时，第一次回车/旋钮短按确认问题；之后旋转浏览随机牌组，短按逐张选牌，直到满足牌阵数量。
- 揭晓后抽中的牌与顺序锁定；左右旋钮只切换当前说明，不改变牌阵。“开始”会清除本次问题和结果并进入新一轮。
- 已确认问题与当前结果保存在本标签页 `sessionStorage`，刷新可恢复；V0.1 的五张示例牌会迁移到当前 78 张牌组。关掉标签页不作为长期保存。存储被禁用时页面明确提示。
- 开始新一轮无需鼠标或弹窗确认：在结果页再次按 S1 即可；页面按钮使用相同动作逻辑。
- 78 张卡牌结构、名称和分类按标准 Rider–Waite–Smith 体系整理；牌面为本项目程序化原创视觉，不复制参考站图片。目前只做正位牌义展示，不接入 AI 解读。

## 板级边界

采用已读取的 easyinput-board-cy 板级资料：EasyInput V2.0 / v2 / AI Keyboard V2.1 指向同一基线。8 键及编码器为物理资源；产品动作属于本项目。网页只处理系统键盘事件，不直接接触 GPIO、共享外设电源、BOOT、Flash 分区或固件。本轮没有操作 EasyInput App、烧录或更改任何开发板配置。

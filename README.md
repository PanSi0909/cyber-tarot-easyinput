# 赛博塔罗 V0.1

第一轮：普通键盘事件输入验证、5 张示例牌、单张抽卡、固定解读。鼠标、电脑键盘与配置后的 EasyInput 共用同一套状态逻辑。没有调用模型、语音服务或设备私有协议。

## 本地启动

在此目录运行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:4173/ 。需要通过 HTTP 服务打开，不能直接双击 HTML（包含 JS 模块）。

## EasyInput 配置

依据第 6 课第 4、5 章：https://waytoagi.feishu.cn/wiki/A64iwQCt5i0T1wkjHqGcMd6OnZf

1. 截图保存当前按键、旋钮与睡眠配置。保留现有固件。
2. S1 配置为普通数字键 1。旋钮逆时针为左方向键，顺时针为右方向键，短按为 Enter。
3. 同步后等待 App 明确确认成功。不同版本的标签名称可能不同，以网页实际收到的 code 为准。不要用固定文字动作代替键盘事件。
4. 网页“输入验证”显示接收到的 code、有效次数、被忽略的重复事件。开启“仅测试输入”可以只测输入，不推进抽卡。
5. S2–S8 在第一轮没有产品动作。需要测试全部按键时，可以临时配置为 2–8，测完恢复。Numpad1–8 与 NumpadEnter 也兼容。
6. 先点击页面空白处，再测试。焦点在输入框、复选框、下拉框、可编辑区或说明标题时不接管操作；弹窗期间按键交给弹窗。

网页不能检测实际硬件连接，不能区分开发板与普通键盘。不显示虚假的“已连接”。按住输入忽略浏览器 repeat 和未释放的重复 keydown；真实固件若发送多组完整按下/松开，网页会如实计数，需要进一步定位。左右方向和一格几次由固件配置及真机决定。

## 抽卡规则

- 按 1 或点击开始，仅洗牌一次；旋钮/方向键循环选择，点击牌背也可选择。
- 回车/旋钮短按或点击确认揭牌；结果来自已洗好的牌组，之后方向、开始、再次确认都不会更改。
- 当前结果保存在本标签页 sessionStorage，刷新可恢复；关掉标签页不作为长期保存。存储被禁用时页面明确提示。
- 重抽必须使用“结束本次，重新抽牌”并确认。纯键盘可用 Tab 导航到此按钮，再用空格激活。
- 固定解读仅供娱乐和自我反思；示例插图为 AI 生成的统一视觉素材，不代表标准塔罗图像。5 张示例为星星、月亮、太阳、愚者、隐者，未包含逆位或完整 78 张牌。

## 验证

运行 `node --test tests/core.test.mjs`。覆盖旋转、重复按下、锁定、恢复、无效保存数据、鼠标和键盘共用流程。

真机待用户验证：

| 项目 | 步骤 | 预期 | 状态 |
|---|---|---|---|
| S1 | 测试模式短按 3 次 | Digit1 或 Numpad1，接受次数 +3 | 待验证 |
| 长按 | S1 按住约 2 秒后松开 | 接受 +1，浏览器重复被忽略 | 待验证 |
| 旋钮 | 慢转右 10 格，再左 10 格 | 各方向接受 10 次；每格一次 | 待验证 |
| 短按 | 旋钮按下松开一次 | Enter 或 NumpadEnter，接受 +1 | 待验证 |
| 完整抽卡 | 关闭仅测试；开始、旋转、确认 | 单次揭牌；后续输入和刷新不换牌 | 待验证 |
| 切换应用 | 切去其他应用再返回 | 本页未被后台键盘操作改变 | 待验证 |

测试记录详见 QA.md。只有用户观察真机后才把上述状态改为通过。

## 板级边界

采用已读取的 easyinput-board-cy 板级资料：EasyInput V2.0 / v2 / AI Keyboard V2.1 指向同一基线。8 键及编码器为物理资源；产品动作属于本项目。网页只处理系统键盘事件，不直接接触 GPIO、共享外设电源、BOOT、Flash 分区或固件。本轮没有烧录或修改 EasyInput App 配置。

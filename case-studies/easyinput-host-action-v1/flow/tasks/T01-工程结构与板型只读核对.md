- **输入**：当前仓库 `course/host-action-v1-starter` 提交 `743368ac86b8fd2a2ff9512d172d32b7baf300db`；`AGENTS.md`、`README.md`、`AI_DEVELOPMENT.md`、`docs/hardware/easyinput-v2-safety.md`；`easyinput-board-cy` 当前板级合同；使用者提供的 App 版本 0.1.33。
- **允许范围**：读取当前 Maker 仓库和板级事实；把本次目标、边界和只读结果写入根级 `flow/`。
- **禁止越过的边界**：不修改固件源码、宿主测试、构建配置、分区、GPIO、BOOT、GPIO8 共享供电、USB／BLE 设备身份或通信协议；不读取或修改 App 源码；不构建、不识别设备、不读串口、不烧录。

- **验收标准**：能用可定位的文件与函数说清“配置→按键输入→动作解释→运输选择→USB／BLE”；板型明确为 EasyInput V2.0／`v2`／AI Keyboard V2.1 同一硬件；没有产生任何非 `flow/` 差异。
- **状态**：本轮只读核对完成；除本任务卡外未修改文件，未运行构建、测试、设备识别、串口或烧录。

## 2026-08-28 本轮目标与禁止边界

- **本轮目标**：用零基础语言说明当前 Maker 固件的工程分层、八个实体按键从 GPIO 到 USB／BLE 的入口，以及必须保护的开发板与设备身份。
- **允许动作**：读取当前 Maker 仓库；使用 `easyinput-board-cy` 读取板级事实并对当前仓库运行只读静态基线扫描；仅在根级 `flow/` 中记录本轮目标与边界。
- **禁止动作**：不修改固件源码、宿主测试、构建配置或其他非 `flow/` 文件；不运行测试或构建；不访问 App 源码；不识别设备、不读取串口、不连接或烧录开发板；不修改 GPIO、BOOT、GPIO8 共享供电、分区、通信协议、USB／BLE 名称、USB 序列号或其他设备身份。
- **App 边界**：EasyInput 0.1.33 是使用者已经准备好的电脑端条件；本轮未读取 App，因此只确认“版本已由使用者指定”，不声称协议入口、配置同步或真实功能已经验证。
- **证据边界**：静态扫描为 `1 PASS / 2 WARN / 0 FAIL`。两个 WARN 是未向扫描器提供构建分支，因此它没有把条件编译内的引脚声明纳入 PASS／FAIL；这不是构建、烧录或实板通过的证据。

## 只读结果指针

- 板级 GPIO 声明：`components/keyboard/include/keyboard/board_pins.h`。
- 配置解析与按键绑定：`components/keyboard/src/config_payload.cpp`。
- 动作与固件事件转换：`components/keyboard/include/keyboard/keymap.h`、`components/keyboard/src/keymap.cpp`。
- 实体输入扫描：`main/platform/gpio_keys.cpp`。
- 主事件入口与分发：`main/app_main.cpp` 的 `handle_input_event()` 与 `dispatch_firmware_event()`。
- USB／BLE 输出：`main/platform/usb_hid.cpp`、`main/platform/ble_hid.cpp`；共享路由规则在 `components/keyboard/src/transport_routing.cpp`。
- 板型扫描结果：ESP-IDF 项目标记 `PASS`，无 `FAIL`；由于 GPIO 声明位于 `EASY_INPUT_BOARD_V2` 条件编译内，扫描器未获得构建分支而给出 `BUILD_BRANCH_UNSELECTED` 和 `PIN_DECLARATIONS_NOT_FOUND` 两个 `WARN`；不将这两个静态工具限制写成板型冲突。CMake 已只允许 `v2`，并为 keyboard 与 main 组件定义 `EASY_INPUT_BOARD_V2=1`。

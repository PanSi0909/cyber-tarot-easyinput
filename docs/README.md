# 资料中心

欢迎来到 Cyber Tarot × EasyInput。这里不是要求你先读完全部源码，而是帮助你按自己的目标找到最短入口。

## 我现在想做什么

| 目标 | 从这里开始 | 你会得到什么 |
|---|---|---|
| 先看看作品 | [GitHub Pages 在线演示](https://pansi0909.github.io/cyber-tarot-easyinput/) | 不安装软件，用鼠标或普通键盘完成一次体验 |
| 在电脑上运行 | [新手实操指南](getting-started.md) | 克隆、启动静态网站并运行测试 |
| 接入 EasyInput | [新手实操指南：可选硬件路线](getting-started.md#第三层30-分钟可选硬件路线) | 配置八键、旋钮和语音输入，不需要烧录 |
| 理解软硬件关系 | [系统架构](architecture.md) | 分清固件、EasyInput App、操作系统和网页的职责 |
| 按课程学习开发 | [第 2–8 课学习路线](learning-guide.md) | 从协议实践逐步走到完整产品 |
| 查看真实验收 | [QA 记录](../QA.md) | 浏览器、自动测试和实体开发板的历史证据 |
| 学习固件开发 | [Host Action v1 案例](../case-studies/easyinput-host-action-v1/README.md) | 完整可构建的第 2 课复刻案例 |
| 参与改进 | [贡献指南](../CONTRIBUTING.md) | 提交问题、文档修正或小范围改进 |

## 推荐给第一次接触项目的人

1. 先完成[在线 5 分钟任务](getting-started.md#第一层5-分钟在线体验)，确认自己理解产品做什么。
2. 阅读[四层架构](architecture.md#四层职责)，避免把网页、App 和固件混成一件事。
3. 按[第 3–8 课实践章](learning-guide.md#第-38-课从输入到产品)阅读产品如何一步步形成。
4. 想动手时再做[本地 15 分钟任务](getting-started.md#第二层15-分钟本地运行)。
5. 有 EasyInput 开发板时，最后尝试可选硬件路线；基础体验不要求购买硬件。

## 如何看待仓库中的不同资料

- `README.md`：项目展示与最快入口。
- `docs/`：面向学习者的稳定说明和课程实践。
- `QA.md`：按时间积累的详细验收证据，不适合作为第一篇教程。
- `COURSE-8-DELIVERY.md`：结课交付、键位表和演示脚本。
- `design/`：视觉方案、牌面生产和设计决策。
- `case-studies/`：可以独立学习的硬件复刻案例。
- Git 历史：查看每一阶段真实发生了哪些修改。

## 阅读边界

课程实践章来自真实开发对话，但不是聊天全文。关键片段已为清晰和隐私进行编辑，移除了本机路径、私人文档、授权过程和过时内部信息。当前功能事实以 `main`、自动测试和 `QA.md` 为准。

官方课程链接可能需要飞书权限；即使无法打开，仓库中的实践章也可以独立阅读。

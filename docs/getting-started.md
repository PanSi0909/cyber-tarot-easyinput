# 新手实操指南

这份指南按门槛分成三层。你可以在任意一层停止：没有开发板，也能完整体验和学习网站。

## 第一层：5 分钟在线体验

### 准备

只需要现代浏览器。打开 [GitHub Pages](https://pansi0909.github.io/cyber-tarot-easyinput/)；页面默认使用本地 mock，不调用付费模型。

### 完成一次单卡流程

1. 点击“开始”，或按键盘数字 `1`。
2. 点击“牌阵选择”，或按数字 `2`。
3. 选择“单卡指引”，用鼠标确认；也可以用方向键移动、`Enter` 确认。
4. 在问题框输入一个用于自我反思的问题并确认。
5. 选择一张牌，查看牌名、位置和正逆位。
6. 点击“综合解读”，或按数字 `4`，查看明确标记的本地 mock 结果。
7. 按 `Escape` 或数字 `8` 返回；已经锁定的牌局不应消失。

### 成功标准

- 不需要注册或填写 API 密钥；
- 鼠标或普通键盘可以完成整个流程；
- 页面明确显示 mock 或本地知识边界；
- 返回操作不会改掉已经确认的问题和卡牌。

## 第二层：15 分钟本地运行

### 准备

- Git；
- Node.js 22 或更新的兼容版本；
- Python 3（只用它启动静态 HTTP 服务）。

### 克隆与启动

```bash
git clone https://github.com/PanSi0909/cyber-tarot-easyinput.git
cd cyber-tarot-easyinput
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 <http://127.0.0.1:4173/>。不要直接双击 `dist/index.html`；`file://` 会改变模块加载、权限和焦点行为。

### 运行测试

另开一个终端，在仓库根目录运行：

```bash
node --test tests/*.test.mjs
```

测试应该全部通过且没有跳过项。具体数量以当前 `main` 和 CI 输出为准。

### 可选服务端模式

```bash
node server.mjs
```

默认仍然是零成本 mock。GitHub Pages 不能运行 `server.mjs`，因此 Pages 上没有 `/api/readings` 和 `/api/insights`。真实模型必须通过服务端环境变量接入，不能把密钥写进 `dist/` 或提交到 Git。

## 第三层：30 分钟可选硬件路线

这一步需要 EasyInput V2.0 和对应配置 App，但不需要修改固件，也不需要运行 `idf.py flash`。

### 推荐映射

| 实体输入 | 配置或职责 | 网页备用输入 |
|---|---|---|
| S1 | 固定文字“开始” | 数字 `1` |
| S2 | 固定文字“牌阵选择” | 数字 `2` |
| S3 | 语音输入 | 数字 `3` 后使用文字输入 |
| S4 | 固定文字“综合解读” | 数字 `4` |
| S5 | 固定文字“历史备份” | 数字 `5` |
| S6 | 固定文字“学习模式” | 数字 `6` |
| S7 | 固定文字“周期洞察” | 数字 `7` |
| S8 | 固定文字“返回” | 数字 `8` 或 `Escape` |
| 旋钮左 / 右 | 左右方向键 | `ArrowLeft` / `ArrowRight` |
| 旋钮短按 | 确认 | `Enter` |

App 的具体字段名称可能随版本变化；配置时以 App 当前界面为准，不要为了网页体验修改 GPIO、分区或设备身份。

### 真机练习

1. 先用普通键盘走通第一层任务，建立软件基线。
2. 打开本地 HTTP 页面并保持浏览器窗口在前台。
3. 用 S1、S2 和旋钮完成单卡牌阵选择。
4. 用 S3 输入问题；语音不可用时，直接改用文字。
5. 抽牌后用 S4 查看解读，再用 S8 返回。
6. 确认一次短按只执行一次，长按不会重复触发。
7. 确认 S8 返回后，问题和锁定卡牌仍然存在。

成功标准不是“按键亮了”，而是实体输入、网页反馈和保存状态形成了完整闭环。

## 常见问题

### 双击 HTML 后功能异常

改用本地 HTTP 命令。浏览器对 `file://` 的模块、麦克风和资源加载限制与真实部署不同。

### EasyInput 输入没有进入网页

先点击网页空白处让窗口获得焦点，再确认没有停留在其他应用或错误输入框。普通键盘可用而开发板不可用时，问题通常位于 App 配置或系统输入层，不要先改网页代码。

### 麦克风被拒绝或不可用

使用页面的普通文字输入继续流程。语音是增强入口，不是完成占卜的必要条件。

### 端口 4173 已被占用

换一个端口，例如：

```bash
python3 -m http.server 4174 --bind 127.0.0.1 --directory dist
```

### Pages 上为什么没有真实 AI

Pages 是纯静态托管，不能安全保存服务端密钥。默认 mock 用于验证产品流程，不应被描述成真实模型输出。

### 我没有开发板

使用数字键 `1`–`8`、方向键、`Enter`、`Escape` 和鼠标即可。硬件不会解锁隐藏功能，它优化的是连续操作体验。

### 我想学习烧录固件

先阅读 [Host Action v1 案例](../case-studies/easyinput-host-action-v1/README.md)和其中的安全说明。构建成功不等于烧录成功，烧录会覆盖设备固件，必须单独确认目标设备和写入范围。
